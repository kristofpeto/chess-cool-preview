# Chess Cool web preview

A browser build of the Chess Cool app, to try it on a phone without installing anything. It is served by GitHub Pages from the `gh-pages` branch at https://kristofpeto.github.io/chess-cool-preview/.

This repository holds only built files. The source is in the private repository `kristofpeto/chess-cool`; `COMMIT.txt` on `gh-pages` names the commit each build was made from. Chess Cool is a mobile app: this preview runs its Flutter UI in a browser, so fonts and system gestures differ from the phones.

Piece artwork: "Celtic" set by Maurizio Monge, MIT licence (see the app's licences page, ⋮ → About).
